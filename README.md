## ส่วนประกอบของเว็บไซต์

### 1. 🧭 Navbar (แถบเมนู)
แถบเมนูด้านบนที่ติดอยู่ตลอดเวลา มีเมนูลิงก์ไปยังส่วนต่างๆ และรองรับ Mobile Menu

### 2. 🎯 Hero (แบนเนอร์หน้าแรก)
ส่วนต้อนรับพร้อมหัวข้อหลัก "บริการเปลี่ยนแบตเตอรี่รถยนต์ 24 ชั่วโมง" และปุ่มติดต่อ 3 ช่องทาง (โทร, LINE, Facebook)

### 3. 🔋 Symptoms (อาการแบตเสื่อม)
แสดง 6 อาการที่บอกว่าแบตเตอรี่รถคุณเริ่มเสื่อม:
- รถสตาร์ทติดยากกว่าที่เคยเป็น
- เสียงแตรรถเบากว่าปกติ
- ไฟหน้ารถสว่างลดน้อยลง
- ระบบไฟในห้องโดยสารผิดปกติ
- อายุแบตเตอรี่เกิน 2-3 ปี
- กระจกไฟฟ้าทำงานช้าลง

### 4. 🛠️ Services (บริการ)
แสดง 5 จุดเด่นของบริการ:
- บริการในพื้นที่ จ.พระนครศรีอยุธยาและใกล้เคียง (ถึงที่ภายใน 30 นาที)
- มีการสำรองไฟก่อนติดตั้งทุกครั้ง (ป้องกัน ECU)
- มีหน้าร้านชัดเจน แบตของแท้ รับประกัน 12 เดือนขึ้นไป
- รับชำระเงินสด/โอน/บัตรเครดิต
- มีแบตทุกรุ่นทุกยี่ห้อ ทั้งใหม่และมือสอง

### 5. ⚡ Brands (แบรนด์แบตเตอรี่)
แสดง 8 แบรนด์แบตเตอรี่ยี่ห้อดังที่มีจำหน่าย:
- FB BATTERY
- 3K BATTERY
- GS BATTERY
- BOLIDEN
- BOSCH
- Panasonic
- PUMA BATTERY
- VARTA

### 6. 📸 Gallery (ผลงาน)
แกลเลอรี่แสดงภาพผลงานบริการ

### 7. 📞 Contact (ติดต่อ)
ข้อมูลติดต่อพร้อม Google Maps แสดงตำแหน่งร้าน

### 8. 📄 Footer (ส่วนท้าย)
ข้อมูลลิขสิทธิ์และลิงก์เพิ่มเติม

## การติดตั้งและใช้งาน

### ติดตั้ง Dependencies
```bash
npm install
```

### รันโหมดพัฒนา (Development)
```bash
npm run dev
```
เปิดเบราว์เซอร์ไปที่ `http://localhost:3000`

### Build สำหรับ Production
```bash
npm run build
```

### รัน Production Server
```bash
npm start
```

### ตรวจสอบโค้ด (Lint)
```bash
npm run lint
```

## การตั้งค่าสีธีม

ธีมสีของเว็บไซต์กำหนดไว้ใน `tailwind.config.js`:
- **Primary (สีหลัก):** `#228B22` - สีเขียว
- **Accent (สีเน้น):** `#FFD700` - สีทอง

ใช้งานผ่าน Tailwind classes:
```jsx
<div className="bg-primary text-white">สีเขียวพื้นหลัง</div>
<div className="bg-accent text-gray-800">สีทองพื้นหลัง</div>
```

## หลักการเขียนโค้ด

### Components
- ใช้ **Functional Components** เท่านั้น
- Export เป็น default: `export default function ComponentName() {}`
- ตั้งชื่อไฟล์แบบ PascalCase

### Styling
- ใช้ **Tailwind CSS** เท่านั้น ไม่เขียน CSS แบบเดิม
- เน้น Mobile-first approach
- ทุกปุ่มต้องมี hover effect
- ใช้ transition สำหรับความนุ่มนวล

### เนื้อหา
- เขียนเป็นภาษาไทยทั้งหมด
- ใช้ Emoji เพื่อความน่าสนใจ
